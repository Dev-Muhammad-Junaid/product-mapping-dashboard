## 2. Here 2 There - Nav App (NEW!)
An interactive destination exploration and planning application.

**Location**: `/Nav App/`

### Features
- 🗺️ Interactive map with draggable destination bubbles
- 🛤️ Visual route planning with animated paths
- 📋 Day planner with drag-to-reorder functionality
- 🌟 Create and share destination lists
- 🎨 Beautiful, modern UI inspired by iOS design

### Quick Start
```bash
cd "Nav App"
pip install -r requirements.txt
python3 init_sample_data.py  # Optional: load sample data
python3 app.py
# Open http://localhost:5001
```
