# Product Mapping Dashboard

This repository contains multiple applications:

## 📊 Project Mapping System
A complete Product Mapping System for ingredient analysis and pattern matching.

## 🚀 Timeline Evolution App
An interactive timeline application that showcases how products evolved through time with world-class design and intuitive navigation.

### Quick Start - Timeline App

```bash
cd "Timeline App"
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:5000` to explore the timelines!

**Features:**
- 🎨 World-class design with smooth animations
- 🎯 Interactive scrubber for precise navigation
- ⌨️ Keyboard shortcuts (←/→, Space, F, +/-)
- 📱 Touch gesture support
- 🎬 Auto-play and fullscreen modes
- 🔍 Zoom controls

See [Timeline App README](Timeline%20App/README.md) for detailed documentation.
